# VSG Releases

Fertige Programme fuer das automatische Update (der Quellcode liegt in privaten Repos).

- `app/`: Tablet-App Scheibenauswertung (APK) und `version.json`
- `desktop/`: VSG Desktop fuer Windows (ZIP, einfach entpacken) und `version.json`

App und Desktop pruefen beim Start die jeweilige `version.json` und bieten neuere Versionen zur Installation an.
